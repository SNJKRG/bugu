# BUGU — сайт

React 19 + TypeScript + Vite, Tailwind v4 (сброс стилей и утилиты), Motion (сцены по скроллу). Две страницы: `/` (история и контакты) и `/menu/` (полное меню; прямая ссылка подходит для QR-кода, `/menu/#deserty` открывает раздел, `/menu/?q=беш` — поиск).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # просмотр собранной версии
```

Публикация не настроена. `dist/` — статические файлы для любого хостинга.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `src/data/site.ts` | Адрес, телефон, WhatsApp, часы, ссылка на карту. Единственное место для правки контактов |
| `src/data/menu.json` | Снимок меню RestaurantGuru (98 позиций, 14 разделов), без изменений |
| `src/data/menu.ts` | Разбор меню: цены в сомах, пометка источника об ИИ вынесена из описания во флаг `sourceImageAi` |
| `src/data/media.ts` | Постеры сцен, будущие видео, фото блюд и зала |
| `src/data/copy.ts` | Тексты глав и секций (предложенные, не цитаты ресторана) |
| `src/home/Story.tsx` | Пять сцен: закреплённая сцена, главы прокручиваются поверх, огонь мерцает по времени |
| `src/menu/MenuPage.tsx` | Меню: поиск, разделы, пустой результат |
| `src/ui/` | Шапка, нижняя панель на телефоне, футер, иконки Lucide |
| `scripts/build-assets.sh` | Сборка WebP из пакета `bugu-complete-production-kit 3` |

## Как подключить видео

Положить ролики в `public/video/` и вписать пути в `src/data/media.ts`:

- `loop` — спокойная петля остановки S01–S05. Играет без звука и только пока сцена на экране.
- `transitionIn` — переход T01–T04 от предыдущей остановки. Проматывается скроллом. Первый кадр должен совпадать с предыдущим постером, последний — с постером этой сцены. Кодировать с короткими GOP (`ffmpeg … -g 6 -keyint_min 6`), иначе перемотка будет дёргаться.

Достаточно одного файла 16:9: на телефоне кадр обрезается по фокусу сцены (`focusX`). Без видео, при `prefers-reduced-motion` или ошибке загрузки сайт работает на постерах.

## Бронь

Кнопки ведут в WhatsApp (с шаблоном сообщения) или в звонок. Сайт заявки не принимает и не подтверждает.

## Заменить перед публикацией

1. **Логотип** — `Wordmark` в `src/ui/Chrome.tsx` и `public/favicon.svg` взяты из приблизительной реконструкции по аватару 150 × 150. Нужен мастер-файл ресторана.
2. **Сцены** — пять концептуальных PNG v2 в разрешении 1672 px. Финальные кадры нужны от 2560 px, плюс видео (см. выше).
3. **Фото блюд** — четыре фото из стороннего меню, подлинность не подтверждена. На двух исходниках обрезана наклейка сервиса. Нужна съёмка ресторана.
4. **Фото зала** — открытые источники (Open Kitchen, RestaurantGuru). Нужны оригиналы.
5. **Часы** — показаны 11:00–23:00 (Instagram). RestaurantGuru даёт 11:00–00:00. Подтвердить и убрать `hoursNote`.
6. **Меню и цены** — снимок RestaurantGuru на 13.10.2026, не подтверждён рестораном.
7. **Иллюстрации блюд** на странице меню — ИИ-рисунки, подписаны как иллюстрации. На рисунке боорсока орнамент посуды придуман генерацией.
